# J.A.R.V.I.S.

Личный голосовой ИИ-ассистент для Windows. Зовёте по имени и разговариваете, а он обращается к вам «сэр», управляет всем ноутбуком, видит экран, пишет и звонит в Telegram, сам замечает важное и слушается с телефона откуда угодно. Мини-реактор всегда поверх окон, а большой реактор в главном окне живёт вместе с его голосом. Всё бесплатно.

## Что нужно

| Что | Зачем | Обязательно |
| --- | --- | --- |
| Windows 10 или 11 | Окна, звук, файлы и плеер управляются через Windows | Да |
| Python 3.11 или новее | На нём работает Джарвис. Проверено на 3.12 | Да |
| Microsoft Edge или Google Chrome | Окно, микрофон и эхоподавление. Edge в Windows уже есть | Да |
| Интернет | Установка, языковая модель, голос | Да |
| Около 350 МБ на диске | Окружение и модель распознавания речи | Да |
| Микрофон и динамики | Разговор голосом. Без них можно писать текстом | Желательно |
| Бесплатный ключ [Groq](https://console.groq.com/keys) | Мозг, карта не нужна. Без ключа работают только короткие команды | Желательно |
| Бот Telegram от [@BotFather](https://t.me/BotFather) | Управление с телефона | Нет |
| Telegram Desktop | «Напиши Алихану», «позвони маме» | Нет |

Всё остальное `Jarvis.cmd` поставит сам. Если Python нет:

```bash
winget install Python.Python.3.12
```

## Как запустить

```bash
git clone https://github.com/Raul12-bit/jarvis.git
```

Или скачайте архив: **Code → Download ZIP**. Затем дважды нажмите **`Jarvis.cmd`** в папке проекта.

1. Первый запуск создаст окружение в `%LOCALAPPDATA%\Jarvis` и поставит зависимости, обычно это пара минут.
2. Откроется окно Джарвиса, на рабочем столе появится ярлык **«Джарвис»**, а в углу экрана мини-реактор.
3. Разрешите браузеру доступ к микрофону и вставьте ключ Groq, когда Джарвис спросит.
4. Скажите: **«Джарвис, сколько времени?»**

Ключи, токены, память и журнал лежат в `%LOCALAPPDATA%\Jarvis`, а не в папке проекта, поэтому в репозиторий не попадают.

**Обновление:** `git pull`, затем запуск через ярлык. Джарвис сам заменит работающую версию и доустановит новые зависимости.

Подключение бота, защита, все команды и решение проблем: **[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)**.

## Удалённое управление

Бот Telegram, а не отдельное приложение: ноутбук сам забирает сообщения с серверов Telegram, поэтому не нужны свой сервер, проброс портов и сборка под Android и iOS, а уведомления и голосовые работают сразу и бесплатно. Кнопки работают без языковой модели и не тратят лимит. Полный список: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md), раздел 4 или `/help` в боте.

Новое в этой версии: живой экран, мышь с точным наведением по сетке, режим терминала с памятью папки, браузер, сеть, дела, любые папки и архивы, панель состояния Джарвиса, журнал и самопроверка с телефона, перезапуск, оповещения о разблокировке, пробуждении и зарядке.

## Полный доступ

Включён сразу, по прямой просьбе хозяина, и настраивается только на самом ноутбуке.

| Что | Голосом и текстом дома | С телефона |
| --- | --- | --- |
| Команды PowerShell | Только чтение сразу, остальное после «да» | Сразу, это прямой приказ хозяина, а не догадка модели |
| Файлы | Обычные папки. AppData, `.ssh`, `.env` и подобное модели закрыты | Любые диски и папки |
| Камера | По просьбе | По команде |
| Что выключает | Настройки, раздел «Полный доступ» | Только с самого ноутбука |

**Почему дома есть вопрос, а на телефоне нет.** С телефона команду пишет сам хозяин словами `/cmd`. Голосом команду формулирует языковая модель по речи, которая могла быть распознана с ошибкой, и по тексту с экрана, который мог написать кто угодно. Поэтому код, а не модель, проверяет: команда только читает и в этой реплике не было чужого текста? Если нет, Джарвис называет команду и ждёт «да». Одна фраза на чужом сайте не должна становиться командой на вашем компьютере.

**Цена полного доступа.** Кто получит ваш аккаунт Telegram, получит и ноутбук. Защита: облачный пароль Telegram и необязательный ПИН в настройках. С ПИНом команды, камера и системные папки открываются на 15 минут после `/unlock`, сообщение с ПИНом бот стирает, а после 5 ошибок закрывает попытки на 15 минут. Если вашему боту напишет посторонний, вам придёт предупреждение.

**Что Джарвис не может и почему:**

- **Окна программ, запущенных от администратора.** Это защита самой Windows. Запускать весь ассистент от администратора значит отдать права браузеру и всему, что он читает, поэтому этого нет. Отдельная команда с повышением покажет запрос UAC на экране ноутбука: с телефона его не подтвердить.
- **Разблокировать экран с телефона.** На заблокированном экране ввод идёт в защищённый рабочий стол. Бот честно об этом скажет.
- **Включить выключенный ноутбук.** Для этого нет работающего кода на самом ноутбуке.
- **Кликать по снимку экрана по догадке модели.** Замер показал промах модели зрения на 200 пикселей, а ошибочное нажатие хуже честного «не могу». С телефона для этого есть сетка `/tap`: куда нажать, решает человек.
- **Печатать в поля паролей.** Никогда, даже по просьбе.

## Голос и имя

Голос актёра не копируется: это чужая личность, и бесплатного способа сделать такое качественно всё равно нет. Вместо этого низкий спокойный мужской голос с обработкой в браузере: чуть больше груди и разборчивости плюс лёгкий металлический отзвук, как из динамика в шлеме. Обработка отключается в настройках.

Замер настоящими запросами из этой сети, 2 ноября 2026, по 20 фраз на голос:

| Голос | Ответил | Задержка | Основной тон | Чистота русского |
| --- | --- | --- | --- | --- |
| Реми (по умолчанию) | 20 из 20 | 1,7 с | 98 Гц | 94 % |
| Брайан | 20 из 20 | 2,0 с | 131 Гц | 96 % |
| Флориан | 20 из 20 | 1,9 с | 142 Гц | 94 % |
| Дмитрий, родной русский | 1 из 20 | | 113 Гц со сдвигом | |

Чистота русского это точность офлайн-распознавания по его речи, а не оценка на слух: слушать я не могу, поэтому выбор легко поменять кнопкой «Послушать» в настройках. Сервис иногда отвечает пустотой на отдельный голос, тогда на пару минут включается другой мужской. Без интернета говорит мужской голос Pavel из самой Windows, и женского голоса не будет ни при каких сбоях, пока Pavel установлен (если его нет, Windows прочитает доступным русским голосом).

Слово «Джарвис», замер на 10 синтетических голосах, включая казахский акцент: 4 фразы на голос, смоделированы шум и эхо комнаты.

| Условия | Сразу | С тихой проверкой Whisper |
| --- | --- | --- |
| Тихо | 92 % | 100 % |
| Комната | 95 % | 100 % |
| Шумно | 95 % | 100 % |
| Очень шумно | 82 % | 100 % |

Из 114 чужих фраз ни одна не разбудила Джарвиса, включая подобранные «Чарльз Дарвин», «джаз», «сервис». Это синтетическая речь, а не ваш голос и микрофон: настоящий журнал покажет остальное.

## Как это устроено

```text
Микрофон → браузер (эхоподавление WebRTC) → WebSocket → Silero VAD → Vosk «Джарвис»
                                                                  ↓ реплика
                              подтверждение → мгновенная команда → языковая модель → инструменты
                                                                  ↓ ответ
Голос ← Web Audio и обработка ← Реми ← мужской род, обращение «сэр», проверка честности
```

Модель не может соврать, что сделала: просьбу о действии Джарвис придерживает до конца ответа, и если модель заявила «включил» без вызова инструмента, этот ответ не прозвучит, а модель получит обязательный вызов инструмента. Род исправляется отдельным фильтром: «я проверила» станет «я проверил», а «она проверила» останется как есть. Обращение в прямых ответах добавляет код, в двух ответах из трёх: дворецкий, который говорит «сэр» в каждом предложении, быстро надоедает.

| Часть | Решение | Почему |
| --- | --- | --- |
| Мозг | Groq (`gpt-oss-120b`, `qwen3.8-27b`, `gpt-oss-20b`), запасной Gemini | Самая низкая задержка среди бесплатных. Лимиты считаются на модель, при ответе 429 Джарвис просто берёт следующую |
| Слово активации | Vosk с грамматикой и тремя вариантами на фразу, затем тихая проверка Whisper | Слово есть в словаре модели, обучать ничего не надо; 2 % одного ядра и только пока кто-то говорит |
| Определение речи | Silero через ONNX, один поток | Точно отличает речь от шума |
| Распознавание | Groq Whisper, запасной Vosk на компьютере | Качество и работа без сети |
| Голос | Microsoft Multilingual через edge-tts, запасные мужские голоса, Pavel из Windows | Бесплатно и без ключа. Соединение прогревается заранее, это экономит около секунды |
| Окно и звук | Edge в режиме приложения | Только браузер даёт бесплатное качественное эхоподавление, без него нельзя перебивать на динамиках |
| Реактор | WebGL2 без библиотек | Весь рисунок один шейдер и облако точек. Кадры идут только на целых делителях частоты экрана: 50 кадров на мониторе 144 Гц дрожат, а 48 ровные |
| Зрение | Groq `qwen3.8-27b` | Единственная бесплатная модель с картинками |
| Текст на экране | Распознавание Windows (`Windows.Media.Ocr`) | Бесплатно и без сети, любые программы, точные координаты |
| Талисман | Слоистое окно Win32 и Pillow, без браузера | Браузерное окно не бывает прозрачным и потребовало бы ещё один процесс рендера |
| Руки | UI Automation и MSAA через comtypes | Без мыши и без снимков; читает страницу за десятые доли секунды |
| Звук и плеер | Медиасессии Windows | Явная пауза: мультимедийная клавиша только переключает и запустила бы остановленное видео |
| Смена версии | Отпечаток кода в `/health` | Ярлык сверяет код в памяти с кодом на диске и заменяет устаревший процесс. Без этого обновление не применялось, пока процесс жил |

### Жизнь в фоне и талисман

Микрофон и эхоподавление живут в браузере, поэтому страница нужна всегда. Когда вы закрываете большое окно, она сразу открывается заново, но скрытой: так Джарвис продолжает слышать имя. Выключить его совсем можно через меню талисмана, настройки или голосом.

Талисман не забирает фокус, не появляется в панели задач, не мешает кликать рядом и не виден на снимках экрана. Если его окно пропало, Джарвис поднимает его снова, а панель «Протоколы» в большом окне и `/jarvis` в боте показывают настоящее состояние.

### Защита от собственного голоса

Эхоподавление браузера, строгий порог определения речи, пока он говорит, и проверка смысла. Когда кто-то заговорил поверх, голос сразу приглушается, реплика распознаётся и сравнивается с тем, что сейчас произносится. Совпало: это эхо, громкость возвращается. Три таких случая подряд выключают голосовое перебивание до перезапуска.

### Подтверждение

Необратимое Джарвис делает только после вашего «да», и проверяет его код, а не модель: страница в интернете не сможет ответить за вас.

| Требует подтверждения | Примеры |
| --- | --- |
| Питание | Выключение, перезагрузка, сон |
| Telegram | Каждое сообщение и звонок: Джарвис называет настоящее имя найденного чата |
| Закрытие рабочих программ | VS Code, Claude, браузеры, Office: только по вашей просьбе и после «да» |
| Нажатия с опасной подписью | Купить, оплатить, отправить, удалить, опубликовать, выйти |
| Ввод в терминал и опасные клавиши | PowerShell, cmd, `win+r`, `alt+f4` |
| Запуск программ из найденных файлов | `.exe`, `.bat`, `.ps1` и подобные |
| Команды PowerShell, которые что-то меняют | С текстом команды в вопросе |
| Завершение программ и удаление файлов | Только в корзину, системные процессы завершать нельзя вообще |
| Выключение Wi-Fi и самого Джарвиса | С телефона до ноутбука потом будет не достучаться |
| Всё необратимое после чтения чужого текста | Страница или снимок велели что-то сделать: напечатать, закрыть, запомнить, запустить |

## Контроль времени

Раз в 5 секунд Джарвис смотрит на активное окно и считает время отдельно для игр, видео и работы. Данные лежат только на этом компьютере.

| Занятие | Лимит подряд | Что происходит |
| --- | --- | --- |
| Игры | 60 минут | За 5 минут просит сохраниться, на лимите предупреждает ещё раз и через минуту закрывает игру так же, как крестик в углу окна. Процесс не убивает. Закрывает только то, что точно игра. Можно настроить только предупреждение |
| Видео и фильмы | 90 минут | За 5 минут предупреждает, на лимите ставит на паузу. После трёх попыток отступает |
| Работа без перерыва | 90 минут | Не чаще раза в час тихо спрашивает, как вы. Ничего не останавливает и не закрывает |

Голосом всегда можно договориться: «ещё 15 минут». **Режим фокуса** («фокус на час» или кнопка): всё это время видео ставится на паузу сразу, а за игру Джарвис ворчит, но не закрывает её.

## Лимиты бесплатного тарифа

Подтверждены заголовками и ошибками Groq на настоящем ключе (ноябрь 2026): 1000 запросов в день, 8000 токенов в минуту и 200 000 токенов в день на каждую модель. У `qwen3.8-27b` есть ещё 1000 токенов ответа в минуту.

Модель получает только нужные группы инструментов и при необходимости подключает остальные, а простое действие Джарвис называет сам, без второго запроса. Короткие команды и кнопки бота лимит не тратят. Когда кончается минутный лимит, Джарвис переходит на следующую модель, а если заняты все, ждёт до 6 секунд.

## Приватность

- Слово «Джарвис» сначала ищется на компьютере. Короткая фраза, похожая на имя, уходит в Groq Whisper для проверки: не длиннее 12 секунд и не больше 120 раз в час. Всё остальное, пока вы к нему не обратились, никуда не уходит. Проверку можно выключить в настройках.
- Во время разговора звук уходит в Groq, а текст реплик, заголовок активного окна и то, что Джарвис о вас запомнил, отправляются в языковую модель. По условиям Groq данные не используются для обучения.
- **Снимок экрана** уходит в Groq только по вашей просьбе.
- Текст ответа Джарвиса отправляется в сервис синтеза Microsoft.
- **Запасной Gemini на бесплатном тарифе** использует запросы для улучшения продуктов Google. Он включается, только если вы сами добавите ключ. Снимки экрана и заголовки окон ему не отправляются.
- Команды с телефона, ответы, файлы и снимки экрана проходят через серверы Telegram.
- Внешний адрес (`/ip`) запрашивается у api.ipify.org только по нажатию.
- Экранное время, история, факты, дела и ключи лежат в `%LOCALAPPDATA%\Jarvis` и не синхронизируются с OneDrive.

Локальный сервер слушает только 127.0.0.1 и проверяет случайный токен, Host и Origin, чтобы посторонний сайт в браузере не мог им управлять.

## Разработка

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt pytest miniaudio
.venv\Scripts\python -m pytest tests --ignore=tests/e2e
```

Сквозные проверки работают с отдельной папкой данных и не трогают настоящего Джарвиса. Запускать их надо с `JARVIS_HOME` или через сами скрипты: из песочницы приложения Claude настоящий запуск `Jarvis.cmd` создал бы окружение в виртуальной копии AppData.
